# ClipboardX

ClipboardX 是一个轻量、隐私优先的 macOS 剪贴板历史工具，用于记录复制历史、快速搜索、快捷复制/粘贴，并为后续多设备同步能力预留扩展。

## 产品定位

> 复制过的内容不再丢失。文本、链接、图片、文件都能快速找回，并可在多台 Mac 间安全同步。

- 文本历史记录
- URL 与文件路径识别
- 图片剪贴板记录与写回
- 内容去重
- 隐私过滤
- 本地 SQLite 持久化
- 搜索、类型过滤与图片缩略图
- Option + V 全局快捷键唤起历史窗口
- 收藏置顶与单条删除
- 来源应用展示
- 自动粘贴开关，需要辅助功能权限
- 设置窗口
- 独立局域网共享窗口
- 自定义敏感过滤规则
- 忽略来源应用

后续可以继续扩展 CloudKit 同步、局域网同步和正式分发签名等能力。

## 当前分支：截图贴片功能

截图功能定位为“剪贴板图片采集与临时对比”，不做完整截图编辑器。

第一版基础实现：

- 只支持区域截图。
- 支持 `Option + Shift + A` 快捷键触发截图并固定。
- 截图完成后默认复制到系统剪贴板。
- 截图完成后默认生成一张图片贴片，浮在当前工作区上方。
- 截图同时保存为 ClipboardX 的图片历史记录，便于后续查找、复制和删除。
- 支持同时存在多张截图贴片，用于并排对比。
- 贴片支持拖动、调整大小、关闭和重新复制到剪贴板。
- 贴片支持“置顶/取消置顶”层级切换；第一版采用普通浮窗置顶，不做绑定外部 App 窗口的跟随逻辑。
- 关闭贴片不删除历史记录。
- 退出 App 后不恢复上次打开的贴片；贴片作为临时参考，历史记录负责长期保存。

暂不纳入第一版的能力：

- 全屏截图、窗口截图。
- 图片标注、马赛克、OCR、长截图、录屏。
- 截图贴片绑定到其他 App 窗口并随窗口移动。
- 退出 App 后自动恢复贴片布局。

## 当前分支：局域网共享功能

局域网共享功能定位为“可信设备之间的手动剪贴板内容发送”，不做默认自动同步。

第一版基础实现：

- 局域网共享默认关闭，用户需要在菜单栏“局域网共享...”窗口中手动开启。
- 支持设置本机设备名。
- 支持在同一局域网内发现其他 ClipboardX 设备。
- 支持设备信任/配对；未信任设备不能直接发送内容。
- 支持从历史记录中手动发送某一条内容到指定已信任设备。
- 第一版支持发送文本、链接和图片；截图贴片产生的截图按图片发送。
- 文件类型第一版不做真实文件传输，可作为路径文本处理或暂不发送。
- 接收端收到内容后弹出待接收提醒，用户确认后保存到本机 ClipboardX 历史记录。
- 确认接收后默认不覆盖系统剪贴板；是否自动复制到剪贴板在“局域网共享...”窗口中配置。
- 发送前继续使用敏感内容过滤规则；命中敏感规则的内容默认不发送。
- 菜单栏提供独立“局域网共享...”窗口，展示待接收内容、已信任设备、发现的设备和接收策略。
- 开发阶段支持单机模拟两个设备；最终验收需要两台 Mac 真机测试。

暂不纳入第一版的能力：

- 默认自动同步全部剪贴板。
- 跨公网同步、账号体系和云端中转。
- 群发给所有设备。
- 同步全部历史记录。
- 真实文件传输。
- 后台静默接收任何设备内容。

## 本地运行

```bash
open ClipboardX.xcodeproj
```

然后选择 `ClipboardX` scheme 和 `My Mac` 运行。工程会构建标准 macOS 应用包 `ClipboardX.app`，并以菜单栏 App 形式启动。

也可以继续使用 SwiftPM 做辅助编译检查：

```bash
swift build
```

如果你本地曾经手动创建过同名 Swift 文件，例如：

```text
Sources/ClipboardX/ClipboardWriter.swift
Sources/ClipboardX/Clipboard/ClipboardWriter.swift
```

需要删除多余文件，Swift Package 的同一个 target 内不允许出现两个相同文件名。
